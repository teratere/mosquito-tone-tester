# 🔊 Mosquito Tone Tester - モスキート音・耳年齢可聴域チェッカー

Web Audio APIによる純粋なサイン波（正弦波）発振を用い、8,000Hz〜22,000Hzの高周波可聴域と耳年齢の目安をテストできるシングルファイルWebアプリケーションです。  
外部音声ファイルゼロ・完全ローカル完結で動作し、オシロスコープ波形描画、自動スイープテスト、聴覚保護のための安全リミッター（最大15.0%固定）および自動オートオフタイマー（最大3秒）を搭載しています。

## ⚠️ 【最重要】健康・身体への影響に関する注意事項（必ずお読みください）

高周波音（モスキート音）は、通常の音響とは異なり身体や聴覚に特有の負担を与える恐れがあります。ご利用前に以下の注意事項を必ずご確認ください。

### 1. 「聞こえない＝安全」ではありません
- 高周波音（特に15kHz以上）は、本人の耳に自覚できなくても、内耳（有毛細胞）には強い音圧エネルギーが届いています。
- 「聞こえないから」といって音量を上げすぎると、**自覚のないまま内耳の細胞を傷める危険（騒音性難聴・音響外傷リスク）**があります。

### 2. 頭痛・めまい・耳鳴り・自律神経への影響
- モスキート音や超高音波を聴き続けると、不快感や頭痛、吐き気、一過性の耳鳴り、自律神経の乱れを誘発することがあります。
- 耳に違和感を覚えた場合は、我慢せずに直ちに再生を中止してください。

### 3. 自動停止タイマーと出力制限（安全二重ガード）
- 耳への継続的な音響暴露を防ぐため、**1回の発振は最長3秒（1〜5秒選択可）で自動的にカチッと完全停止**する安全タイマーをシステム的に強制しています。
- 突発的な大音量を防ぐため、音量スライダーの上限を**最大15.0%に強制固定**しています（推奨音量: 3.0%〜5.0%）。

### 4. ペット（犬・猫等）がいる部屋での再生禁止
- 犬（約45kHz）や猫（約64kHz）などの動物は人間よりもはるかに高周波に敏感であり、強いストレスや苦痛を感じます。
- **ペットのいる室内や近距離でのスピーカー再生は絶対に行わないでください。**

## 🌟 主な機能 (Features)

### 1. 純粋サイン波リアルタイム合成 (Web Audio API)
- **8,000Hz 〜 22,000Hz 連続発振:** 1Hz単位のスライダー微調整、および `±10Hz` / `±100Hz` のクイック加減ボタンに対応。
- **突入ノイズ防止:** クリック時の不快な破裂音（ポップノイズ）を防ぐマイクロフェードイン／アウト機構を内蔵。

### 2. 年齢目安プリセット & 自動スイープテスト
- **ワンタップ試聴:** 8,000Hz（〜60代）から17,400Hz（代表的モスキート音・10代）、20,000Hz（極限限界）まで即座に切替可能。
- **自動周波数スイープ:** 周波数を8k〜20kHz（または20k〜8kHz）へ徐々に引き上げ、どの周波数で音が聞こえなくなったかをスムーズに特定。

### 3. リアルタイム・オシロスコープ (Canvas API)
- `AnalyserNode` を介して Canvas 上に波形をリアルタイム描画。
- 人間の耳には聞き取りづらい超高周波であっても、音波が実際に出力されているかを視覚的に確認可能。
